> **Context:** This repository contains the code and workflow analysis for the final Capstone project of the **Genomic Data Science Specialization** (Johns Hopkins University). The project focuses on executing a complete Next-Generation Sequencing (NGS) pipeline, from raw read processing to biological interpretation.

## 📌 Project Overview
The objective of this project was to analyze genomic data to identify significant variants and changes in gene expression. The workflow bridges command-line processing with statistical analysis in R.

**Key Competencies Demonstrated:**
* **NGS Pipeline Execution:** Handling raw FASTQ data, alignment, and assembly.
* **Variant Calling:** Identifying Genomic variants (SNPs/Indels) relative to a reference genome.
* **Transcriptomics:** Conducting Differential Expression Analysis (DEG) to find upregulated/downregulated genes.

## 🛠️ The Pipeline
I implemented a hybrid workflow utilizing **Galaxy** for heavy-lifting alignment tasks and **Command Line/R** for downstream analysis.

### 1. Pre-processing & Alignment
* **Input:** Raw Sequencing Reads (FASTQ).
* **QC:** Quality control checks using FastQC.
* **Alignment:** Mapped reads to the reference human genome (hg19/hg38) using **Bowtie2/BWA** via the Galaxy platform.

### 2. Genomic Assembly & Variant Calling
* **Tools:** Samtools, Mpileup.
* **Process:** Generated VCF (Variant Call Format) files to identify single nucleotide polymorphisms (SNPs) and insertions/deletions.

### 3. Differential Expression Analysis (RNA-Seq)
* **Tools:** Bioconductor (TopHat & Cuffdiff).
* **Analysis:** Calculated FPKM values to quantify gene expression levels between control and test samples.
* **Statistical Validation:** Used R to filter for statistically significant genes (p-value < 0.05).
